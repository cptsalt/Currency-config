the config file is meant to set up currency in a thematic and visual way. The system should be versatile enough to support most types of money

note that anything past the "symbol" entry is not required and can be left out if the unit doesn't need it

{
    "common": {
        "walletName": "Coin Purse", // what the wallet will be called in panes and command results

        "startingMoney": "10s", // how much starting money (if any) a new player should receive. You can delete this if you want NO money to be given to new players
        "noMoneyMsg": "^red;coinless^reset;" // what message will appear in someone's wallet if they have no money
    },
    "units": {

            "color": "#eef", // the color of the unit for use in the wallet, optional
            "icon": "/items/generic/crafting/platinumbar.png" // the icon for the unit in the wallet, optional
